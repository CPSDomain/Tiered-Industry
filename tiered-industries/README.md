| Mod | What it is | Download | Changes |
|---|---|---|---|
| [Tiered Industries](tiered-industries/) | Tiered power, machines, storage and autocrafting, fission and fusion, rockets, and a Stargate to sixteen planets. Everything runs on Forge Energy. | [Releases](https://github.com/CPSDomain/Modding/releases) | [Changelog](tiered-industries/CHANGELOG.md) |
| [Tiered Arsenal](tiered-arsenal/) | Weapons and armour - new ores and tiered gear, each tier built from the one below. Companion to Tiered Industries. | [Releases](https://github.com/CPSDomain/Modding/releases?q=tieredarsenal) | [Changelog](tiered-arsenal/CHANGELOG.md) |

## Downloads
Every version is on the [Releases](https://github.com/CPSDomain/Modding/releases) page with its jar attached - put the jar in your `mods` folder. Each mod's releases are tagged with its name (`tieredindustries-v…`, `tieredarsenal-v…`). Tiered Industries checks for new versions itself: Forge's Mods screen shows when an update is out.

## How releases are made
Each mod lives in its own folder. Pushing a change to a mod's folder builds it on GitHub (Actions tab); when its version number is new, a Release is published automatically with the jar and that version's changelog.
